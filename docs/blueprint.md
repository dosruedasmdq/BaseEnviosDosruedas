# **App Name**: Envios Dosruedas

## Core Features:

- Página Principal Limpia (Landing Page): Una interfaz moderna construida en Next.js con un llamado a la acción claro para solicitar o rastrear envíos.
- Librería de Componentes UI Base: Un conjunto de componentes reutilizables (botones de acción, campos de texto para direcciones, tarjetas informativas) estilizados con Tailwind CSS.
- Thematic Design Tokens: A centralized interface to adjust primary colors, spacing, and typography across all base components for consistent branding.
- Optimized Export Engine: Pack and download component code into a clean file structure ready to be imported into any create-next-app project.

## Style Guidelines:

- Primary Blue: #0636A5, used for main branding, primary buttons, and headers.
- Primary Yellow: #FFF12E, used for accents, highlights, and secondary calls to action.
- Base White: #FFFFFF, used for backgrounds, cards, and clean spacing.
- Headings (Display/Impact): Anton SC or Bebas Neue for strong, impactful titles.
- Body and UI Elements: Outfit for professional clarity and modern legibility.
- Source: Google Fonts import for Anton SC, Bebas Neue, and Outfit (wght 100..900).
- Clean, service-oriented layout that prioritizes clear calls to action and easy navigation for shipment tracking.
